CANVAS NOTE
This is a self-contained interactive HTML guide with JavaScript feedback and progress tracking.
Canvas may remove JavaScript when HTML is pasted into the Rich Content Editor. Use the same
deployment method used for the earlier interactive guides.

The guide is low-stakes. Student responses remain only in the open browser page and are not saved,
graded, or submitted.

QUALITY-CONTROL NOTES
- The eight scored multiple-choice items are evenly distributed: A=2, B=2, C=2, D=2.
- Correct answers are not consistently the longest option.
- Every matching dropdown uses a deliberately shuffled descriptor order; descriptors do not
  appear in the same sequence as the listed terms.
