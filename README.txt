CANVAS NOTE

Canvas may remove JavaScript when HTML is pasted into the Rich Content Editor. Use the same
deployment method used for the Human Development and CLDV-03 interactive guides.

The guide is low-stakes. Student responses remain only in the open browser page and are not saved,
graded, or submitted.

QUALITY-CONTROL NOTE
The multiple-choice answer positions are intentionally varied. Correct answers are distributed
across A, B, C, and D, and answer length was not used as a cue.
